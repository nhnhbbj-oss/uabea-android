# UABEA Android

Unity Asset Bundle Extractor 的 Android 移植版。

## 作者

- B站：https://b23.tv/xhTs9EN
- GitHub：https://github.com/nhnhbbj-oss

## 功能

- 打开 AssetBundle / .assets 文件
- 查看、编辑、导出、导入资产
- 贴图预览与替换（支持大部分格式）
- 音频预览与替换（参考UABE）
- 批量导入/导出贴图、音频
- Mod 制作（.emip 补丁包）

## 下载

从 [Releases](https://github.com/nhnhbbj-oss/uabea-android/releases) 页面下载最新 APK。
